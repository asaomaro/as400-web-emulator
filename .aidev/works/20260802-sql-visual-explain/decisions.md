# 判断の記録

autonomous 実行中の重要判断を残す（protocol「10. 逸脱記録」）。

## D0: 実行モードを interactive → autonomous に切り替えた（2026-08-02）

spec 承認のゲートで、利用者から「design 後、spec 確定、コーディング、テスト、PR まで自律的に進めて。
どうしても確認が必要な事柄があれば停止して」と指示された。

- `state.yml` の `mode` を `autonomous` に変更。`humanGates` は空のまま（部分自律にしない）。
- **停止する条件**（＝「どうしても確認が必要」の運用定義）:
  1. 要件の意味が変わる分岐に当たったとき（`explain only` のときと同種）
  2. 取り消せない・外向きの操作が必要になったとき（実機のデータ変更、索引の実作成、PR の merge）
  3. 実機やホストの制約で受け入れ基準が満たせないと確定したとき
  4. `maxSendBacks`（3）に達したとき
- **PR は作成して停止する。merge はしない**（protocol「10. 終端」）。
- テストが通らないまま PR を出す場合は **draft PR** にして未解決点を報告する（同「安全弁」）。

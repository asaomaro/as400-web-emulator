## 途中で見つけた自分の誤り

**「MCP にプログラム呼び出しが無い」は誤りだった。**
`host_call_program` が `host-server-tools.ts:307` に既にあった。
`mcp-tools.ts` だけを grep して、**ホストサーバー系が別ファイル**にあることを見落とした。

さらに実装中、それを重複と誤認して**一度削除した**（全件テストで発覚し復元）。
`requirement.md` / `research.md` に訂正を明記した。

**訂正後の値打ち**: 既存ツールは**生バイト（base64）専用**で、呼ぶ側が EBCDIC と
詰め 10 進を自分で組む必要があった。型付きの変換がこの作業の本体。

## out / inout の実機往復（2026-08-04 に追加）— 11/11

`ASAOLIB/PGMTST` を作って確かめた（`scripts/build-pgmtst-osaka.mjs`）。
**CL の `PARM` は参照渡し**なので、1 引数で inout をそのまま試せる:

```
&NUM（詰め 10 進 15,5） = &NUM * 2
&TXT（文字 20）        = 'ECHO:' + &TXT
```

```
OK  **inout の数値が往復する**（21 → 42） — "42.00000"
OK  **inout の文字が往復する**（ABC → ECHO:ABC） — "ECHO:ABC            "
OK  **負の値も往復する**（-1.5 → -3） — "-3.00000"
OK  **小数も往復する**（0.00003 → 0.00006） — "0.00006"
```

**負の値と小数を分けて見たのが要点。** 符号ニブルの取り違えは負でしか出ず、
桁合わせの取り違えは小数でしか出ない。正の整数だけだと両方すり抜ける。
